# Security Boundary

Crosshair is a display-only overlay.

- It does not identify, open, scan, read, write, inject into, or hook game processes.
- It does not modify game files or libraries.
- It does not synthesize or intercept game input.
- It has no network control endpoint and does not communicate with game services.
- It does not require administrator/root privileges or a kernel driver.
- Runtime control is limited to the local settings window.

The overlay can still be prohibited or detected by game-specific anti-cheat systems. Do not describe it as an anti-cheat bypass.
